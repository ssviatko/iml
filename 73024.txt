
Registers (24 bit address/counter/offset registers, shadowed Z80 style, except base pointer and stack pointer)

A0 = Source Index (SI)
A1 = Destination Index (DI)
A2 = misc
A3 = misc
A4 = Offset (OFF)
A5 = Counter (CNT)
A6 = Base Pointer (BP)
A7 = Stack Pointer (SP)

Data Registers (16 bit, shadowed Z80 style, except Z register)

R0 = Always contains zero (Z)
R1 = Accumulator (A)
R2 = Argument (G)
R3 = Remainder (RM)
R4
R5 = Result (RZ)
R6 = Doubleword Result High (DH)
R7 = Doubleword Result Low (DL)

Width Specifiers

B = Byte (8 bits)
W = Word (16 bits)

Register Spec byte (RS)

7 = reserved (always 1, future 32/64 flag)
6 = Width specifier (1=word 0=byte, address operations this is always 1)
5 = Ry/Ax bit 2
4 = Ry/Ax bit 1
3 = Ry/Ax bit 0
2 = Rx/Ay bit 2
1 = Rx/Ay bit 1
0 = Rx/Ay bit 0

Bit Position Constant (BC)

7 = 0
6 = 0
5 = 0
4 = 0
3 = word: bit 3 of constant byte: 0
2 = bit 2 of constant
1 = bit 1 of constant
0 = bit 0 of constant

Trap Specifier (TS)

0000-7FFF = User defined traps, user defined interrupt vectors at trap vector table
8000-FFFF = External traps

Address handling/computation

E0 RS       ALD Ax, #$immediate24           ;load address register with immediate 24 bit value/address (load effective address)
E1 RS       ALD Ax, Ay                      ;load Ax with Ay
E2 RS       ALD Ax, $absolute24             ;load address register from absolute address location
E3 RS       ALD Ax, $rel16                  ;load address register from relative address location
E4 RS       ALDL Ax, Rx                     ;Load lower 16 bits of address register from Rx.W
E5 RS       ALDH Ax, Rx                     ;Load high 8 bits of address register from Rx.B
E6 RS       ALD Ax, [Ay]                    ;Load address register from address pointed to by [Ay]
E7 RS       ALD Ax, [Ay]+OFF                ;Load address registe from address pointed to by [Ay] plus OFF
E8 RS       ALD Ax, [Ay]+con16              ;" plus relative constant

EA RS       AST Ax, $absolute24             ;store address register in absolute address location

Assembler Conventions

Address label or 24 bit constant:

Mylabel     EQU $1bfc00
            LD.B A, #@Mylabel               ;All labels and equates are preceeded by a @ sign.

Relative addresses:

            ALD CNT, #$00bbff
DoIt:       ...
            LOOP !@DoIt                     ;generates 16 bit relative address
            RET                             ;Return after CNT repetitions

Relative constants:

MyConst     EQU $3FA
            LD.W A, [BP]+8                  ;BP + 8. No prefix character, assumes positive decimal number
            LD.W A, [BP]-6                  ;BP - 6, No prefix character, assumes negative decimal number
            LD.W A, [BP]+$100               ;BP + 256, $ prefix, assume hexadecimal number, + makes it positive 16 bit constant.
            LD.W A, [BP]-@MyConst           ;BP - $3FA @ prefix, assume equate or label. - negates it and makes a negative 16 bit constant.

NOTE that ! prefix creates a positive or negative 16 bit constant based on current address position relative to argument.
The + and - prefixes create a positive or negative 16 bit constant based on 0 relative to argument.
All labels/equates are 24 bits in size and will be truncated to the appropriate size (8/16/24 bits) depending on the instruction format.

Byte slices:

Addr1       EQU $995522
            LD.B A, #@Addr1                  ;Loads $22 into A through automatic truncation
            LD.B A, #$ffeedd                 ;Loads $dd into A through automatic truncation
            LD.B A, #<@Addr1                 ;Loads $55 into A
            LD.B A, #^@Addr1                 ;Loads $99 into A
            LD.W A, #@Addr1                  ;Loads $5522 into A through automatic truncation

Originator: change origin address

            ORG $120000
            ...                              ;Subsequent assembly will begin at $120000....
            ORG $FC9800
            ...                              ;Subsequent assembly will continue at $FC9800
            DFS 64                           ;Data area 64 bytes in size
            DFB $FC                          ;Define byte $FC
            DFW $9DBF                        ;Define word $9DBF (little endian)
            DFA $1CBF80                      ;Define address $1CBF80 (little endian)

            DFF
            DFD
            DFE                              ;Define float, double extended (future)
